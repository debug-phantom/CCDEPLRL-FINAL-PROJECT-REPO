# CCDEPLRL-FINAL-PROJECT-REPO
REPO FOR DEEP LEARNING 


PLEASE READ THE Posture_Classifier_Manual TO OPERATE THIS PROGRAM TO STREAMLIT 

Q: WHAT DOES THE PROJECT DO?
A: THIS PROJECT TRAINS TWO TYPES OF DEEP LEARNING MODELS (CNN AND MOBILENETV2) TO CLASSIFY FIVE BODY POSTURES FROM IMAGES. THE APP LETS YOU TRAIN EITHER MODEL, VIEW ACCURACY AND LOSS CHARTS, UPLOAD AN IMAGE, AND GET A PREDICTED POSTURE WITH A CONFIDENCE SCORE. IT INCLUDES A CALIBRATION OPTION TO REDUCE OVERCONFIDENCE IN THE CNN MODEL, WHILE THE MOBILENETV2 MODEL PROVIDES HIGHER CONFIDENCE (80-95%). THE ENTIRE APPLICATION RUNS IN STREAMLIT AND IS DESIGNED FOR BODY LANGUAGE AND POSTURE ANALYSIS.
